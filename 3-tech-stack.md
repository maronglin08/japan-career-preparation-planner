# 3. Tech Stack

The first version will be a simple responsive web application. The stack is suitable for a beginner project and avoids unnecessary backend services.

| Technology / tool | Purpose |
|---|---|
| HTML5 | Page structure and content |
| CSS3 | Layout, responsive design, and visual styling |
| JavaScript | Task list, study records, and checklist interactions |
| Browser localStorage | Save a user's data on the same device without creating accounts |
| Visual Studio Code | Write and edit the code |
| Git and GitHub | Track changes and store the project repository |
| GitHub Pages | Host the static website |

## Hosting and deployment
The source code will be stored in a public GitHub repository. The website will be published with GitHub Pages from the main branch. After testing changes locally, I will commit and push them to GitHub, then check the published website on both desktop and mobile screens.

## Scope and limitations
V1.0 will not require user accounts, a database, or a payment service. Data saved in localStorage stays in that browser on that device; users should not expect automatic syncing or backup. The application will not collect sensitive personal information.
