# 5. Launch Plan

## First 50 users
**Primary channel:** TUJ student communities and student groups, with permission from group administrators.

I will introduce the app to international students who are preparing for internships or employment in Japan, share the GitHub Pages link, and ask interested students to try it. I will not send unsolicited bulk messages.

## Value proposition
A simple, beginner-friendly planner that helps international students in Japan organize job-preparation tasks, Japanese study, and 履歴書 preparation in one place.

## Pre-launch QA checklist
- [ ] All three Must Have features work as described.
- [ ] Users can add, complete, and delete tasks.
- [ ] Japanese study records and checklist progress remain after refreshing the same browser.
- [ ] The layout works on desktop and mobile screens.
- [ ] Buttons, links, labels, and instructions are clear.
- [ ] No test data or personal information is included in the public version.
- [ ] The published GitHub Pages link opens correctly.

## Launch-day checklist
- [ ] Publish the tested V1.0 version on GitHub Pages.
- [ ] Open the live link and test the main features once more.
- [ ] Share a short introduction and the link in the approved TUJ student channel.
- [ ] Explain that data is stored only in the user's browser and is not synced between devices.
- [ ] Ask early users to report bugs and confusing instructions.
- [ ] Record feedback and prioritize fixes for the next version.
